# DataClass

DataClass is a professional learning management application for data analytics courses. The current codebase contains the Step 1 application foundation, reusable UI system, responsive role-based dashboard shell, and static teacher/student previews.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

See `PROJECT_CONTEXT.md` for scope and `docs/BUILD_PLAN.md` for the delivery roadmap.
